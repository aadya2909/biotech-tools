# Contributing to biotech-tools

First off, thank you for considering contributing to this project.

This project is built as a learning-driven bioinformatics tool, and contributions of all kinds are welcome — whether it's fixing bugs, improving code, or suggesting new features.

---

## How you can contribute

### 1. Reporting issues

If you find a bug or unexpected behavior:

* Clearly describe the problem
* Include steps to reproduce it
* Attach screenshots or error messages if possible

---

### 2. Suggesting features

Have an idea to improve the project?

* Open an issue with a clear explanation
* Explain why it would be useful
* Keep it focused and practical

---

### 3. Contributing code

To contribute code:

1. Fork the repository

2. Clone your fork locally

3. Create a new branch:

   git checkout -b feature/your-feature-name

4. Make your changes

5. Commit your changes:

   git commit -m "Add: short description of your change"

6. Push to your fork:

   git push origin feature/your-feature-name

7. Open a Pull Request

---

## Code guidelines

* Keep code simple and readable
* Follow existing project structure
* Add comments where necessary
* Avoid unnecessary complexity

---

## Project goals

This project aims to:

* Explore real-world bioinformatics workflows
* Work with NCBI data using Python
* Build practical computational biology tools

---

## Final note

Even small contributions matter.

If you're learning bioinformatics or Python, this project is meant for you — don't hesitate to contribute.

Thank you for being part of this journey.
